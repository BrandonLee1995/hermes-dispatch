## 变更

已将 C端平台运营部 Mac、产品研发部公共 Windows 电脑的 `default` profile
各自 `.env` 中的 `A2A_MAX_PINGPONG_TURNS` 设置为 **20**。
两端之前均未显式设置该变量，采用 Hermes 默认值 5；本次各新增一行：

```dotenv
A2A_MAX_PINGPONG_TURNS=20
```

这是 Hermes 0.21.0 已提供的配置项，源码将其约束在 1–20，用于防止同一
`context_id` 无限互调。本次没有修改程序、插件、模型路由或凭据。
两端在空闲时按既有机制正常重启 Gateway，随后 QQ/A2A 均 connected。

### 独立的工具可用性观察

Windows 源端重启后首次 QQ 尝试 `L20-RD-9` 报告当前工具清单没有 `a2a_call`，

这与之前的首次工具可用性现象一致，本次未修改配置以处理它，也未将根因定性为
