Date: 2026-10-20. Base: upstream `main` at `b2d5c77`.
This record summarizes the publishable implementation and the checks rerun for
the PR. Earlier dated reports are historical snapshots, not a claim that every
host currently runs every version in this branch.

unchanged. The optional MCP script must be installed/configured separately.

included. Public peer aliases are examples of configuration, not baked-in routes.

## Remaining limits / 尚未验证

This PR run checks the App backend, not desktop GUI interaction. It does not
repeat historical live-channel acceptance or test long-history compaction.
The proactive-collaboration policy remains a proposed blind experiment: identity,
directory visibility and route recognition are not proof of autonomous tool use.
Existing Hermes threads intentionally retain previously injected instructions
after disabling the plugin; rollback stops future injection rather than erasing
conversation history.
